# SholiteTech Creatives Flyer Generator

A responsive, client-side personalized event flyer generator. The supplied flyer artwork is bundled at `assets/flyer-template.png` (1229 × 1536 px). Participant photos are processed locally in the browser; no account or server upload is used.

## Run locally

1. Extract this folder.
2. Open a terminal in the project folder.
3. Run a local static server (recommended because browsers may restrict local file access):

   **Python**
   ```bash
   python -m http.server 8000
   ```

4. Visit `http://localhost:8000`.
